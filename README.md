# GitHub 工作素材库

本目录用于集中存放与 GitHub 相关的重要材料、排查记录和可复用模板，方便按主题归类检索。

## 目录说明

- issues/：Issue 跟进、需求记录、排查说明、截图/日志附件。
- prs/：PR 评审意见、变更说明、合并前后对比、复现/回滚材料。
- checks/：CI/检查失败日志、排查过程、修复记录。
- checklists/：发布前检查、PR 评审等可勾选清单模板。
- assets/：截图、录屏、设计稿、日志片段、导出文件等素材。
- templates/：Issue/PR/排查报告等模板，方便统一格式。

## 使用建议

- 按仓库或主题建子目录，例如 issues/repo-a、prs/repo-b。
- 文件名尽量包含日期和关键词，便于检索。
- 敏感信息脱敏后再存放。
- 可直接复制 templates/ 里的模板开始记录。

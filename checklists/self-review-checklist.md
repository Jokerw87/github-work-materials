# 提交前自检清单（Self-Review Checklist）

本地提交 / 推送前逐项确认，避免把不该提交的内容带上去。

## 改动自检
- [ ] 只提交本次目标相关的改动，无杂散文件
- [ ] 调试代码、console.log、临时注释已清理
- [ ] 没有影响他人的配置文件被误改

## 质量
- [ ] 本地能跑通，无新增报错
- [ ] 命名 / 格式符合规范

## 安全
- [ ] 无密钥、Token、密码写入仓库
- [ ] 截图 / 日志已脱敏

## 提交信息
- [ ] commit message 说明“做了什么、为什么”

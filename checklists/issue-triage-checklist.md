# Issue 分诊清单（Issue Triage Checklist）

处理新 Issue 时逐项确认，分诊完成后再进入排期。

## 信息完整性
- [ ] 复现步骤清晰可跟
- [ ] 环境 / 版本信息齐全
- [ ] 有「预期行为」与「实际行为」的对比

## 分类与优先级
- [ ] 已打标签（bug / feature / question / docs）
- [ ] 已评估影响范围与优先级（P0–P3）
- [ ] 已指派负责人

## 跟进
- [ ] 关联了相关 PR / 文档
- [ ] 结论已记录到 `issues/` 对应文件

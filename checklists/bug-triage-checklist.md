# Bug 分诊清单

## 接收时

- [ ] 复现步骤是否清晰、可稳定复现
- [ ] 影响范围（用户量 / 功能模块 / 严重程度）
- [ ] 是否阻塞核心流程（登录 / 支付 / 下单等）
- [ ] 是否已有相同或重复的 Issue（先合并，避免重复跟进）

## 定级

- [ ] 严重程度：S0 致命 / S1 严重 / S2 一般 / S3 轻微
- [ ] 优先级：P0 立即处理 / P1 本周 / P2 排期 / P3 待定
- [ ] 指派负责人

## 处理前

- [ ] 收集日志 / 截图 / 录屏，放入 `assets/`（注意脱敏）
- [ ] 明确验收标准与复现环境（系统 / 版本 / 账号）

## 修复后

- [ ] 自测通过（主路径 + 边界情况）
- [ ] 补充 / 更新回归用例
- [ ] 关联并关闭对应 Issue
- [ ] 必要时同步用户 / 客服

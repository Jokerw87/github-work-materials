# 发布前检查清单

## 变更范围

- [ ] 关联 Issue/PR 已说明白
- [ ] 变更范围已收敛，没有无关改动
- [ ] 需要迁移、兼容、性能说明时已补齐文档

## 代码与评审

- [ ] PR 描述完整，可复现/可验证
- [ ] 关键逻辑有注释或补充文档
- [ ] 已确认至少有 1 人评审

## 测试

- [ ] 单测/集成测试已覆盖本次逻辑
- [ ] 本地或 CI 验证通过
- [ ] 边界/异常路径有说明或降级策略

## 安全与合规

- [ ] 密钥、凭证、个人信息已脱敏
- [ ] 依赖变更、许可证风险已确认
- [ ] 破坏性变更有迁移说明或回滚方案

## 上线准备

- [ ] 发布说明已更新
- [ ] 监控、日志、告警已确认
- [ ] 回滚步骤已准备

# 发布前检查清单（Release Checklist）

在合并 / 发布前逐项确认，全部打勾后再操作。

## 代码与构建
- [ ] 本地构建通过，无报错
- [ ] 必要的自动化检查（lint / 测试）通过
- [ ] 无明显未提交改动（git status 干净）

## 变更内容
- [ ] 变更范围与需求一致
- [ ] 已清理调试代码、临时日志
- [ ] 兼容性或破坏性变更已明确标注

## 文档与沟通
- [ ] 相关文档 / README 已同步更新
- [ ] 相关人员已知会

## 发布后
- [ ] 回滚方案明确
- [ ] 监控 / 验证手段到位

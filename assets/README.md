# assets 目录规范

## 分类建议

- `issues/`：Issue 配图、复现日志、排查截图
- `prs/`：评审截图、修改前后对比
- `checks/`：失败日志、告警截图、控制台导出
- `infra/`：环境说明、拓扑图、配置片段

## 命名建议

- 尽量使用日期前缀，例如：`2026-07-25-issue-123-log.png`
- 文件名小写，单词用连字符分隔
- 避免中文空格、特殊符号

## 安全与脱敏

- 上传前脱敏：密钥、token、密码、手机号、邮箱
- 不要上传完整私钥、原始凭证、内部用户隐私数据
- 若必须保留关键信息，建议做局部打码

## 大小控制

- 小文件直接存，大文件考虑使用外部存储并放链接
- 避免无意义重复截图
- 目录下建议保留简短说明文件，方便检索

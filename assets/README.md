# assets/ 素材使用规范

本目录存放截图、录屏、设计稿、日志片段、导出文件等素材。

## 命名规范
- 格式：`YYYYMMDD-主题-序号.扩展名`，例如 `20260725-login-error-01.png`
- 文件名只用小写字母、数字、连字符，避免空格和中文（中文可放在内容里）

## 存放建议
- 按来源 / 主题建子目录，例如 `assets/screenshots/`、`assets/logs/`
- 大文件（>10MB）优先压缩或放对象存储后再入库，避免仓库体积膨胀

## 注意事项
- 截图中的账号、Token、个人信息需打码脱敏
- 不存放可执行文件或敏感原始数据
- 引用素材时使用相对路径，例如 `../assets/screenshots/xxx.png`

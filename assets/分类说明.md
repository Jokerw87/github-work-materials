# assets/ 分类说明

按素材类型分子目录存放，便于检索与复用。

## 推荐结构
- assets/screenshots/：界面截图、报错画面（命名 `YYYYMMDD-功能-序号.png`）
- assets/logs/：终端 / 运行日志片段（`.log` 或 `.txt`，脱敏后）
- assets/designs/：设计稿、流程图、原型导出
- assets/exports/：报表、数据导出文件

## 各类型注意
- 截图：必须打码账号 / Token / 手机号等敏感信息；优先 PNG，长图用拼接或分段
- 日志：删除内网 IP、密钥、cookie；大日志只截关键段
- 设计稿：保留源文件链接，导出图放 designs/
- 导出文件：说明来源与口径，避免同名覆盖

## 引用方式
在 issues/、prs/ 文档中用相对路径引用，例如：

`![报错截图](../assets/screenshots/20260725-login-error-01.png)`
